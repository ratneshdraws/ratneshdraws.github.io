RATNESH PORTFOLIO WEBSITE

Files:
- index.html: page structure and content
- styles.css: responsive light-theme styling
- script.js: mobile navigation and artwork lightbox
- assets/: the selected portrait, logo and nine artwork images

Preview:
Open index.html in a browser. No build tools are required.

Before publishing:
1. Confirm the social profile URLs in index.html.
2. If you want to use a different About portrait, replace assets/about-portrait.png.
3. Upload the complete folder to your hosting provider, keeping the assets folder beside index.html.

The website uses Google Fonts when an internet connection is available and falls back to system fonts otherwise.
